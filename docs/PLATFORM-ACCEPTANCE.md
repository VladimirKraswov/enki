# Приёмка установленного приложения

Сборка в CI проверяет код и пакет на конкретной ОС. Она не доказывает установку,
работу модели, системные разрешения или GUI на компьютере пользователя. Для каждой
приёмки фиксируйте commit, версию, SHA256 пакета, ОС/архитектуру, сценарии и результаты.
Незапущенный сценарий остаётся `not-run`. Используйте отдельный профиль и тестовые
чаты; исходные истории владельца не изменяйте ради эксперимента.

## Общие сценарии

- Установка/обновление точного пакета; версия приложения и runtime видны раздельно.
- Сохранены настройки, ID чатов, архивы и файлы изменяемых историй; архив читается,
  явное продолжение работает без повторения старых инструментов.
- Встроенное ядро запускается без установленного агентского CLI. Тестовый промпт,
  инструмент, остановка и ожидаемый ответ отражают фактическое состояние.
- Доступ инструментов соблюдается; повторное открытие чата не создаёт разрешение заново.
- Проекты переключаются без подвисания, утраты черновика и событий чужого чата.
- Вложения, диктовка, восстановление фрагмента, браузер, MCP и результаты доступны.
- Очередь исполняется однократно; остановка и неопределённая доставка не вызывают replay.
- Таймеры можно создать, посмотреть и отменить; закрытие окна и полный выход различаются.
- Hub и ключи работают после перезапуска; выключенная передача данных остаётся выключенной.
- Удалённый хост при ошибке не подменяется локальным. Используется выделенный тестовый хост.
- Обновление, отмена, ошибка загрузки/сборки и откат оставляют понятный статус и сохраняют данные.

## macOS

Подпись, runtime manifest, microphone entitlement и DMG проходят штатные проверки.
Finder-запуск использует встроенный Node. Keychain, микрофон, папки и локальная сеть
проверяются с реальным системным разрешением пользователя. Закрытие скрывает окно,
трей/Dock возвращает его. Для отдельного WebView-профиля требуется поддерживаемая ОС.

## Windows

NSIS устанавливает текущего пользователя; проверяются WebView2, системный сейф,
микрофон и пути с пробелами/кириллицей. Подпроцессы не показывают консоли и принадлежат
Job Object; завершение подтверждает очистку своего дерева. Нативные возможности
проверяются по объявленному контракту, а не по успеху теста на другой системе.

## Linux

Проверяются содержимое пакета, установка на поддерживаемый desktop, WebKit/GTK,
XDG-пути, разблокированный Secret Service, микрофон/звук и SSH. Xvfb-проверка не
заменяет запуск в пользовательской desktop-сессии.
