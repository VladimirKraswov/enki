# Разрешения macOS

Enki показывает единый **центр разрешений** при старте после обновления и в
**Настройки → Приложение → Разрешения**. Он проверяет только те доступы,
которые приложение действительно использует:

| Доступ | Для чего | Как запрашивается |
| --- | --- | --- |
| Запись экрана | Снимки и проверка окон, управление компьютером | `CGPreflightScreenCaptureAccess` / `CGRequestScreenCaptureAccess` |
| Универсальный доступ | Чтение интерфейса и отдельный курсор агента | `AXIsProcessTrusted` / `AXIsProcessTrustedWithOptions` |
| Микрофон | Диктовка по явному нажатию | `getUserMedia` в WebView; запись не начинается автоматически |
| Полный доступ к диску | Файлы вне выбранных папок | только вручную: системные настройки |
| Файлы и папки | Рабочий стол, Документы, Загрузки, проекты | только вручную: системные настройки |

## Почему после обновления переключатель может быть включён, но не работать

Enki сейчас подписан **adhoc** (`Signature=adhoc`, без TeamIdentifier). macOS
TCC запоминает не только bundle ID, но и code requirement/`CDHash`. После
пересборки `CDHash` меняется, а старая запись остаётся. В логе `tccd` это
выглядит как:

```text
Failed to match existing code requirement for subject
dev.local.opencodedesktop and service kTCCServiceScreenCapture
```

Центр разрешений видит фактический отказ и после обновления предлагает
**Перепривязать**: удаляется только старая запись Enki для этого доступа
(`tccutil reset`) и запрос выполняется заново. Если macOS всё равно не
показывает запрос, открывается точный раздел системных настроек.

`tccutil reset` не выдаёт разрешение сам: пользователь по-прежнему подтверждает
доступ в системном диалоге или переключателем. Enki никогда не обходит TCC и не
меняет базу TCC напрямую.

## Ограничения

- **Full Disk Access** не имеет официального API запроса или preflight-проверки;
  приложение только открывает нужный раздел настроек.
- **Файлы и папки** также выдаются только пользователем; доступ к выбранным
  проектам не означает полный доступ к диску.
- После выдачи **Записи экрана** macOS может применить доступ только после
  полного перезапуска Enki. Кнопка перезапуска недоступна, пока в Enki есть
  активные задачи.
- Стабильная подпись (Developer ID или постоянный сертификат) устранила бы
  повторную привязку TCC после каждой сборки; без неё центр разрешений — штатный
  способ восстановить доступ.
