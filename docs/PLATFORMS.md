# Платформы и сборки

Единая кодовая база: React/TypeScript, Tauri/Rust и встроенное Enki Runtime.
Версии манифестов проверяет `test/bundle-config.test.ts`. Бинарник называется
`enki`; стабильный OS identifier сохраняется для доступа к профилю и ключам.

| Платформа CI | Пакет | Команда на этой ОС |
|---|---|---|
| macOS 14, ARM64 | `.app` и `.dmg` | `npm run build:macos` |
| Windows 2022, x64 | NSIS `.exe`, текущий пользователь | `npm.cmd run build:windows` |
| Ubuntu 24.04, x64 | `.deb` | `npm run build:linux` |

GitHub Actions собирает эти пакеты на отдельных временных машинах соответствующих
ОС. Сборка Windows/Linux не происходит на Mac и не устанавливает приложение на
компьютеры владельца. [Workflow](../.github/workflows/desktop.yml) сохраняет
артефакты и receipt с commit, версией, размером, SHA256 и версиями инструментов.
Живая проверка установленных приложений проводится [отдельно](PLATFORM-ACCEPTANCE.md).

## Зависимости локальной сборки

- Node/npm и Rust/Cargo. Подготовка проверяет поддерживаемый host Node до импорта
  модулей `node:sqlite`; закреплённый runtime Node упаковывается отдельно.
- macOS: Xcode Command Line Tools. Удобная npm-команда использует ad-hoc подпись;
  Developer ID и нотариализация требуют отдельно настроенной доверенной личности.
- Windows: MSVC Build Tools, Windows SDK и WebView2 по требованиям Tauri.
- Linux: GTK/WebKitGTK, OpenSSL, `pkg-config` и build tools. Команда
  `npm run check:linux-prereqs` сообщает недостающие пакеты, но не устанавливает их.

Настройки платформ лежат в `src-tauri/tauri.{macos,windows,linux}.conf.json`;
ресурсы runtime подключаются через `tauri.runtime.conf.json`. Системные ключи:
Keychain, Windows Credentials или Secret Service. На Linux нужна разблокированная
сессия Secret Service. Наличие функции определяет runtime-контракт, а не догадка UI
по операционной системе. Cua Driver — отдельная интеграция со своими ограничениями.

## Подготовка и владение процессами

`npm run tauri -- build …` вызывает `scripts/runtime/tauri-entry.mjs`: проверяет
host Node, готовит точный SDK-артефакт или проверяет полный существующий manifest
и receipt, затем запускает закреплённый Tauri CLI. Ошибка, отмена или несовпадение
контрольной суммы не допускает дальнейшую сборку.

На Windows `enki-build-runner` компилируется из этих же исходников до подготовки.
Дочерний процесс назначается в kill-on-close Job Object до выполнения; таймаут
или остановка завершает принадлежащее задаче дерево. Раннер проверяется по receipt,
не берётся из случайного PATH и не заменяется незащищённым запуском.
На Unix используется собственная группа процессов; неподтверждённая очистка
сообщается как `ENKI_BUILD_CLEANUP_UNKNOWN`, а не успех. Лимиты времени, вывода
и дочитывания pipe обязательны. Нельзя сигналить переиспользованный PID.

## Обновление и установка

Установка использует механизм целевой ОС и проверенный пакет. Она ждёт простоя,
сохраняет парную копию данных и не завершает чужие процессы. На Windows NSIS
работает с текущей установкой пользователя; Linux пакет может запросить штатное
системное подтверждение; macOS сохраняет предыдущий bundle для отката.
[Обновления](HUB-UPDATES.md) · [Первая установка Windows](WINDOWS-BOOTSTRAP.md).

Нативная сборка macOS в CI использует runner macOS 15 ARM64. Версия хоста
сборки не меняет заявленную минимальную версию macOS у приложения.
