# Кэш нативной сборки

Основное обновление Enki — готовый пакет GitHub, подтверждённый подписанным
описанием Hub. Компиляция на устройстве остаётся дополнительным вариантом.
Кэш ускоряет именно её; он не заменяет проверку подписей, тесты и установку.

## Как работает

При локальной сборке подключённая Enki получает от своего Hub временный доступ
к кэшу компилятора. `sccache` 0.19.0 скачивается из официального выпуска Mozilla;
архивы шести поддерживаемых платформ закреплены SHA256 в
[манифесте инструмента](../scripts/build-cache/sccache-lock.json).

Библиотеки Rust сохраняются по ключам, которые sccache вычисляет из входных
файлов, компилятора и параметров. Зависимости Cargo из постоянного реестра могут
использоваться в новых папках сборки; собственные исходники и зависимости с
абсолютными путями могут потребовать повторной компиляции. Инкрементальный режим Rust выключен только в
этой сборке. Финальная компоновка, процедурные макросы и другие неподдерживаемые
вызовы по-прежнему выполняются локально. При смене компилятора или зависимостей
часть записей перестаёт подходить; фиксированное ускорение не обещается.

Кэш на Hub разделён по парному устройству и ОС/архитектуре. Устройство не может
записать или прочитать чужую секцию. Это сохраняет пользу после очистки локальной
сборки, не превращая произвольный подключённый компьютер в поставщика исполняемых
объектов для остальных устройств. Готовыми проверенными установщиками устройства
пользуются совместно через основной канал обновлений.

## Ограничения и отказоустойчивость

- Общий лимит 8 ГиБ, до 3 ГиБ на устройство, до 64 МиБ на объект.
- Hub сохраняет минимум 2 ГиБ свободного места; вытесняет давно не использованные
  записи, удаляет записи без обращения 30 дней. Обслуживание запускается также
  штатным таймером Hub. Кэш не входит в резервную копию истории SQLite.
- Доступ ограничен четырьмя часами и только методами кэша; отзыв устройства
  прекращает доступ сразу. Сборщик не получает постоянный ключ Hub или ключ выпуска.
- Локальный адаптер доступен только на loopback со случайным ключом. Соединение
  с Hub использует настроенный HTTPS-сертификат; перенаправления не выполняются,
  содержимое сверяется по SHA256 до передачи компилятору.
- После двух ошибок запросы к Hub прекращаются до следующей сборки. Пропуск записи,
  отключённый Hub и переполнение хранилища оставляют обычную локальную компиляцию.
- Enki запускает собственный экземпляр sccache и завершает его после сборки.
  Временные инструменты удаляются; чужой глобальный кэш и процессы не затрагиваются.

В настройках обновления отображаются использованные и сохранённые библиотеки.
Первая сборка наполняет кэш. Старый каталог `target`, собранный без sccache,
нельзя автоматически превратить в его объектный кэш.

## Проверка

`npm run test:build-cache` проверяет ограничения локального адаптера и отключение
при сбое. Набор включён в `test:runtime-artifact`. Серверные проверки входят в
`python3 -m unittest discover -s services/hub/tests`.

Явная проверка с настоящими Rust/sccache и одноразовым HTTPS Hub:
`node scripts/build-cache/live-check.mjs`. Она использует только временный профиль,
удаляет первую папку сборки целиком и требует попадание зависимости Cargo
в удалённый кэш из новой папки. `--tool-archive /путь/к/архиву` позволяет
повторно использовать скачанный официальный sccache; SHA256 проверяется так же.
Не запускает модели, приложение или пользовательские чаты.

Справочные ограничения: [Mozilla sccache](https://github.com/mozilla/sccache/blob/v0.19.0/docs/Rust.md),
[конфигурация](https://github.com/mozilla/sccache/blob/v0.19.0/docs/Configuration.md).
