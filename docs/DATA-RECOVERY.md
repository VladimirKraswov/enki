# Данные, импорт и восстановление

Enki хранит собственные данные в `enki`: на macOS — `~/.local/share/enki`,
на Linux — в выбранном XDG data root, на Windows — `%LOCALAPPDATA%\enki`.
`ENKI_PROFILE_DIR` задаёт отдельный проверочный профиль без обращения к данным
владельца. Точные правила путей — `src-tauri/src/paths.rs` и
`src-tauri/resources/agent/src/platform/paths.ts`.

## Хранилище

В `<app-data>/runtime` находятся `runtime.sqlite`, транскрипты `sessions/` и
неизменяемые источники импорта `legacy/`. База содержит метаданные, команды,
события, очередь, таймеры и журнал миграции; транскрипты содержат сообщения SDK.
Черновики, UI-настройки, вложения и журнал диктовки принадлежат профилю WebView.
Ключи обслуживает системное хранилище, а не база истории.

Папка проекта имеет канонический путь. Собственные JSONL лежат в шарде
`sessions/<sha16(canonical directory)>`; рабочие копии импортированных Pi-чатов
имеют отдельную проверяемую раскладку. Перед запуском очередей и воркеров ядро
доводит журнал переноса: сверяет владение и SHA256, восстанавливает отсутствующую
копию, обновляет метаданные одной транзакцией. При конфликте сохраняет обе копии.
Ошибка одного чата не скрывает остальные. Диагностика доступна через `/migrations`.
UI переносит привязки папок и черновики только по подтверждённым записям журнала.

## Импорт и продолжение

Импорт OpenCode и Pi CLI читает источники без изменения оригиналов и сохраняет
происхождение и ID. Архив OpenCode остаётся только для чтения; продолжение
создаёт рабочий чат через проверенный механизм. Кнопка «Продолжить чат» находится
рядом с полем ввода: черновик и вложения переносятся, отправка остаётся отдельным
действием. Повторные нажатия открывают то же продолжение. Исторические инструменты
и промпты не выполняются повторно. Сид продолжения не наследует счётчики размера
прежнего контекста; стоимость архивного хода сохраняется отдельно.

Импорт очередей и таймеров журналируется поэлементно. Очереди приходят на паузе,
таймеры выключены; неопределённая доставка остаётся неопределённой. Локальная
копия удаляется только после подтверждения соответствующего элемента. Несвязанные
записи показываются с причиной, а не теряются за общим флагом «импорт завершён».

## Обновление и откат

Установщик получает блокировку обслуживания и подтверждённый простой, затем
делает парную копию базы и всех изменяемых JSONL с манифестом SHA256. Откат
возвращает обе части к одному моменту; новые данные сохраняются в отдельном
`failed-update-*`. Копия одной SQLite без файлов сессий недостаточна.
[Подробный контракт](SDK-UPGRADE.md), [удалённый установщик](REMOTE-RUNTIME.md).

При диагностике сверяйте список ID, число сообщений/частей архивов и наличие
изменяемых файлов до и после операции. Пустой первый ответ во время загрузки
истории сам по себе не доказывает потерю данных. Не удаляйте источник или копию,
пока целостность и доступность нового хранилища не подтверждены.

## Совместимость путей и системной идентичности

Первичный переход `opencode-desktop` → `enki` выполняется журналируемым
переименованием. Ссылка совместимости может сохранять прежние абсолютные пути.
Её можно убрать после проверки всех собственных привязок; при существующем
каноническом хранилище удалённая ссылка не создаётся заново. Если два каталога
содержат разные данные, автоматическое объединение запрещено.

Главный бинарник — `enki`, приложение — `Enki.app`. Стабильный OS identifier
`dev.local.opencodedesktop`, пространства системного хранилища и проверка подписи
сохраняются: их переименование создало бы другой профиль или потерю доступа.
Независимые CLI, их базы и службы не принадлежат приложению и не удаляются.
macOS может отдельно запросить разрешения после изменения подписи;
[как диагностировать доступ](ACCESS.md).
