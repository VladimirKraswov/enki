# Воспроизводимые проверки задач

`scripts/evaluations` — ограниченный испытательный стенд, не производственный
агентский цикл. Он создаёт свои проекты, даёт фиксированную задачу, проверяет
результат независимыми assertions и сохраняет все исходы, включая отказы.
Истории владельца и глобальные настройки не используются.

## Offline

```sh
npm run eval:check
npm test -- test/evaluations.test.ts
```

Фикстуры содержат сломанные исходные варианты и эталоны; проверка должна отвергать
первые и принимать вторые. Browser-фикстуры проверяют формы, восстановление и
изменение viewport. CI не делает запросов к платным или локальным моделям.

Неизменяемые результаты прежней квалификации, которые проверяют контрольные суммы
и воспроизводимость исходов, лежат в `test/fixtures/evaluation-archive/`.
Они являются тестовыми данными. Старые имена, версии и ошибки внутри них сохраняются
побайтно; это не текущая инструкция, рейтинг моделей или новое измерение скорости.

## Живой прогон

Единственный исполняемый adapter — `pi-sdk` из закреплённого runtime lockfile.
Стенд использует его агентский цикл и свои fixture-инструменты; он не проверяет
полный Enki daemon, UI, очередь или аренду Hub. Устаревшие внешние adapters
отказывают с `EVAL_ENGINE_RETIRED`, не запускают чужие CLI.

Живая модель требует отдельного разрешения, свободного ресурса и заранее заданных
лимитов. Пример после настройки разрешённого провайдера:

```sh
npm run eval:live -- --cases zero-value --repeats 1 --output .local/evaluations/smoke
```

Точные параметры проверяет текущий `scripts/evaluations/runner.mjs`. Не помещайте
ключи в командную строку или отчёт. Облачный adapter читает явно предоставленный
ключ; локальный принимает только разрешённый loopback endpoint без редиректов и
проверяет served model. Вход, выход, число запросов, общий deadline и объём
результатов ограничены. Browser-пробы используют отдельный временный профиль.

## Интерпретация

Сохраняйте commit стенда, модель, реально применённое усилие, bounds и все попытки.
Не смешивайте неизвестный usage с нулевым. Timeout и лимит бюджета — не успешный
результат. Изменение тела задачи, assertions или sampling делает сравнение другим
экспериментом. Режимы памяти/навигации сравнивают на одинаковых задачах и порядке.
Не выводите качество всей модели, большого контекста или production UI из нескольких
синтетических задач. Живой прогон не запускается чтением этого документа.
