# Обновления Enki

Версия в исходниках, опубликованный релиз и установленное приложение — разные
состояния. Обновление должно показывать конкретный этап, причину отказа и способ
повтора; потерянное подтверждение нельзя считать разрешением повторить мутацию.

## Действующий транспорт

Hub отдаёт stable/preview через проверенный HTTPS origin и ключ устройства.
Передача истории может быть выключена: обновления от неё не зависят.
Каждый релиз содержит два полных подписанных пакета — интерфейс `hot` и исходники
`source`. Закреплённый ключ проверяет подпись, версия и native fingerprint
определяют совместимость. В пакеты не входят ключи, локальные receipt или истории.

- Совместимый native fingerprint позволяет заменить UI после сохранения черновиков,
  вложений и журнала диктовки. Нативное ядро при этом не перезапускается.
- Изменение native fingerprint требует нативного пакета. В действующем клиенте
  он собирается из проверенного source в отдельном рабочем каталоге.
- Повтор не переиспользует повреждённую попытку: создаётся новый каталог, прежний
  лог сохраняется. Компоненты повторно скачиваются лишь при ограниченном временном
  сетевом сбое; checksum/TLS-ошибка не маскируется повтором.
- Ошибка подписи, несовместимый новый пакет и отмена показываются явно.
  Проверенный старый hot UI после успешной нативной установки снимается как
  заменённый; подлинная порча остаётся ошибкой.

**В работе:** готовый платформенный пакет с GitHub как основной вариант
«Обновить и перезапустить», локальная сборка как явный дополнительный вариант
при наличии инструментов. До окончания реализации и проверки этот документ
не утверждает, что скачивание готового пакета уже доступно в установленной версии.
Статус — [ROADMAP](../ROADMAP.md).

## Установка и сохранность данных

Установка берёт блокировку обслуживания, получает авторитетный простой runtime,
делает парную копию базы и изменяемых сессий. Помощник ждёт завершения приложения,
проверяет подготовленный артефакт и применяет его механизмом ОС. При отказе
сохраняются диагностические данные и возможность согласованного отката.
Секреты не входят в UI/логи; подписи, ownership и identity не обходятся.
[Восстановление](DATA-RECOVERY.md) · [Платформы](PLATFORMS.md).

Закрытие окна скрывает приложение в трей и оставляет агентов работающими.
Полный выход и установка используют штатный lifecycle. Старые сборки очищаются
только после проверки новой; чужие процессы, CLI, базы и резервные копии не удаляются.

## Выпуск

```sh
npm run release:local -- stable
# либо preview
```

Команда выполняет [канонические проверки](VERIFICATION.md), затем публикует
один проверенный commit через локального оператора или ключ подключённого устройства.
Изолированный signer Hub хранит приватный ключ; его не копируют в CI или на клиенты.
Права устройства, native fingerprint, версии, безопасные пути и CAS канала
проверяются повторно перед публикацией. Загруженный код на Hub не выполняется.
[Мастерская и авторизация выпуска](SELF-DEVELOPMENT.md).

Проверьте `.local/releases/<version>-<channel>.json`, served head и подписи обоих
пакетов с фактическими файлами этого commit. Upload без этих проверок не является
доказательством доступности обновления. GitHub-публикация использует тот же commit.

## Ручная загрузка исходников

Hub предоставляет LAN HTTPS-маршруты:

- `/downloads/latest` — версия, размер, SHA256 и неизменяемая ссылка.
- `/downloads/latest/source.zip` — stable-исходники.
- `/downloads/source/{payloadSha256}.zip` — конкретный снимок.
- `/downloads/source/{payloadSha256}.json` — оригинальный подписанный пакет.

Маршруты не открывают приватные API Hub. Проверяйте TLS по доверенному сертификату,
затем размер/hash; обычный ZIP не заменяет оригинальную подпись updater-пакета.
[Windows](WINDOWS-BOOTSTRAP.md). Preview не подменяет stable.

## Сервер

Контракт и хранение реализованы в `services/hub/releases.py`,
`device_updates.py`, `release_signer.py`; клиент — `src-tauri/src/hub_updates`.
[Операторская инструкция](../services/hub/README.md). Не изменяйте неизменяемый
пакет под тем же digest/версией. Совместимые маршруты читают старые клиенты, но
они не являются самостоятельным исполняющим ядром Enki.
