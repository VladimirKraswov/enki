# Первая установка или ручное обновление Windows

Используйте готовый проверенный NSIS-пакет той версии, которую требуется установить,
если он опубликован. Сборка из исходников нужна при отсутствии пакета или для
проверки изменений. Mac не компилирует Windows-пакет: для этого используются
Windows-машина или Windows runner CI.

## Из исходников

1. Получите адрес Hub и проверенный публичный сертификат от владельца. Загрузите
   `/downloads/latest`, затем неизменяемый `source.url` с того же HTTPS origin.
   Сверьте `source.bytes` и SHA256. Не отключайте TLS и не принимайте произвольный
   сертификат. Прямой `/downloads/latest/source.zip` удобен для ручной загрузки,
   но может смениться между запросами; manifest фиксирует конкретный снимок.
2. Распакуйте в новую короткую папку, например `C:\work\Enki-<version>`.
   Не перезаписывайте checkout или данные установленной программы.
3. Проверьте Node/npm, Rust MSVC, Visual Studio C++ Build Tools, Windows SDK и
   WebView2. Приватный ключ подписи релиза для локальной сборки не нужен.
4. Выполните последовательно с проверкой кода завершения:

   ```powershell
   npm.cmd ci
   npm.cmd run build
   npm.cmd run build:windows
   ```

   NSIS находится в `src-tauri\target\release\bundle\nsis`.
   Сверьте версию, размер и SHA256; сохраните receipt сборки.

## Установка

Сохраните данные и штатно завершите Enki из трея после завершения задач: крестик
скрывает окно. Установите NSIS в существующую папку текущего пользователя без
uninstall с удалением данных. Стабильная OS identity сохраняется. Не завершайте
посторонние приложения и службы.

Откройте Enki, проверьте версию, встроенный runtime, чаты, архивы, настройки и
одну разрешённую тестовую задачу. Введите отдельный ключ этого устройства для
Hub либо сохраните существующий; Mac/admin key не копируется. Проверьте страницу
обновлений. «Обновлений нет» допустимо, если установлена опубликованная версия.
