# Библиотека и сервис Hub

Hub — частный сервис одного владельца и нескольких его устройств. Он хранит
версии общих пакетов, разрешённые данные о задачах, память проектов, каталог
моделей и подписанные обновления. Он координирует GPU, но не исполняет агентский
цикл и не запускает загруженный исходный код.

## Подключение

В настройках библиотеки задайте HTTPS origin, проверенный публичный сертификат
и отдельный ключ устройства. Новый компьютер получает собственный ключ; admin
key и ключ другого устройства ему не передают. Ключ хранится в системном сейфе.
Для macOS отдельно может потребоваться доступ к локальной сети.

Web UI использует отдельную авторизацию. Проверка сертификата в приложении не
выдаёт системное доверие всему компьютеру. Не отключайте TLS для устранения ошибки.
Текущая операторская конфигурация — [services/hub](../services/hub/README.md).

## Пакеты

Навыки, промпты, шаблоны и MCP выбираются явно. Навыки входят в общий реестр Enki,
промпт дописывается в черновик без отправки, MCP импортируется выключенным без
секретов. Для SSH-runtime файлы устанавливают на его хосте, а не подставляют путь
с другого компьютера. Пользовательские изменения и выключенные записи сохраняются.
Выбранные текстовые пакеты проверяются периодически при простое; новый пакет сам
не устанавливается. Исполняемые изменения MCP требуют просмотра.

Пакеты проверяются по путям, размеру и контрольным суммам. Сервер хранит файлы,
но не запускает scripts. Локальные инструменты и политика доступа определяют,
когда и как навык может использовать свой вспомогательный код.

## Данные и приватность

Новые устройства по умолчанию не передают историю. Метрики и видимый текст
включаются явно; скрытые рассуждения, исходные файлы, аудио, скриншоты, аргументы
и полные результаты инструментов не передаются. Тексты ограничены, известные
форматы секретов фильтруются на клиенте и сервере; это не гарантия удаления
произвольных персональных данных. Для чувствительных задач выключайте передачу.
Выключение не удаляет уже отправленные записи автоматически.

Outbox сохраняется локально и связан с origin/сертификатом; сбой Hub не повторяет
inference. Переполнение имеет явный счётчик. Usage берётся из ответа, неизвестные
показатели не оцениваются. Одобрение задач для экспорта и карточка результата —
разные действия. Автоматической тренировки моделей нет.

Сервис не разделяет независимых пользователей: ключ устройства открывает общие
данные владельца в пределах его прав. Утерянный ключ отзывают. Резервные копии
Hub содержат приватные данные и ключи; держите их вне Git и публичных пакетов.
