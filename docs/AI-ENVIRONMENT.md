# Карта среды Enki

Эта карта описывает роли узлов и известную конфигурацию, а не их живую доступность.
Перед изменением сервиса проверьте его текущие настройки и статус. Ключи, пароли,
истории и персональные рабочие данные сюда не включаются.

```text
Enki: интерфейс + нативный супервизор
  └─ Enki Runtime: встроенный Node + Pi SDK
       ├─ инструменты и файлы на выбранном компьютере / SSH-хосте
       ├─ Hub: каталог, очередь аренды GPU, статус и маршрут точной модели
       │    ├─ RTX 5090: Strata → Qwen Flash Next
       │    └─ V100: координатор профилей → соответствующий inference-движок
       ├─ настроенные облачные API (например DeepSeek)
       └─ MCP/навыки → браузер, изображения и другие явно подключённые сервисы
```

## Узлы

| Узел | Назначение | Инструкция |
|---|---|---|
| Приложение Enki | Интерфейс, профиль, ключи, обновление; собственный runtime | [Архитектура](ARCHITECTURE.md) |
| CT206, Hub | Библиотека, модели, аренды, память, подписанные релизы | [Hub](HUB.md), [сервис](../services/hub/README.md) |
| VM5200, RTX 5090 | Strata и Qwen Flash Next; inference gateway | [Strata](../services/strata/README.md) |
| VM5100, V100 | Профили Qwen/Gemma/Artemis и переключение движков | [V100](../services/v100/README.md) |
| CT201, CPU Inference | ASR и генерация/редактирование изображений | [ASR](../services/asr/README.md), [изображения](../services/images/README.md) |
| Выбранный SSH-хост | Собственное проверенное Enki Runtime и рабочие файлы | [Удалённый runtime](REMOTE-RUNTIME.md) |

Адрес Hub, сертификат и ключ устройства задаются на клиенте. Реестр управления
моделями хранится на Hub; закрытые ключи шлюзов не передаются клиентам.
Адрес ASR и API изображений можно заменить в настройках. Не зашивайте приватный
IP в пользовательский workflow как единственно возможный сервер.

## Жизненный цикл запроса

1. Runtime проверяет чат, доступ, контекст и выбранную модель.
2. Для управляемой модели получает аренду Hub; интерфейс показывает очередь и
   выгрузку/загрузку. HTTP 200 или список `/v1/models` не равны готовности весов.
3. Запрос начинается только после подтверждения точной модели. Аренда сохраняется
   между инструментальными шагами, чтобы другой клиент не выгрузил используемые веса.
4. Результаты и команды фиксируются в хранилище Enki; неопределённая доставка
   сверяется по ID без повторного запуска.

Инструменты работают там, где находится runtime. Удалённый GPU не получает
право исполнять локальные shell-команды. Hub не является вторым агентом или
сервером генерации токенов. Выход из приложения прекращает только принадлежащие
ему процессы; инфраструктурные службы и независимые CLI не затрагиваются.
