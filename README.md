# Enki

Enki — настольное приложение для работы с ИИ над кодом, файлами и задачами.
Приложение поставляется со своей средой выполнения на Pi SDK. Отдельный агентский
CLI не требуется. Модели подключаются через Hub или настроенные API провайдеров.

![Иконка Enki](src/assets/enki-icon.png)

## Возможности

- Чаты в проектах и без проекта; рабочие файлы и история сохраняются между запусками.
- Инструменты для кода, терминал, просмотр изменений, браузер, MCP, навыки и расширения.
- Очередь задач с изменением порядка и уточнениями для текущего хода; таймеры наблюдения.
- Локальные и облачные модели: в выборе отображаются доступные подключения;
  Hub координирует загрузку моделей и занятость GPU.
- Диктовка с распознаванием по ходу речи и восстановлением незавершённых фрагментов.
- Генерация и редактирование изображений, наборы иконок и карт материалов через
  настроенный сервис. Результаты доступны в чате и рабочей папке.
- Работа на этом компьютере или на явно выбранном SSH-хосте; общая библиотека и
  память проектов через Hub. Ключи хранятся в системном хранилище.
- «Мастерская» для доработки Enki с проверками и публикацией обновлений.

## Начало работы

Установите пакет для своей системы, откройте Enki и настройте Hub или провайдера
модели. Создайте чат, выберите проект либо работу без проекта, модель и режим
доступа. Адрес модели не определяет место выполнения инструментов: его задаёт
выбранный компьютер.

«Полный доступ» управляет инструментами агента. Системные разрешения на микрофон,
файлы, локальную сеть и хранилище ключей подтверждаются отдельно средствами ОС.

## Разработка

Нужны Node/npm, Rust/Cargo и системные зависимости Tauri для целевой платформы.
Проверенные версии Node и SDK закреплены в `scripts/runtime/sdk-contract.mjs`.

```sh
npm ci
npm run build
npm test
```

Нативная сборка готовит встроенную среду выполнения автоматически:

```sh
npm run build:macos
# На Windows: npm.cmd run build:windows
# На Linux: npm run build:linux
```

Используйте отдельный профиль `ENKI_PROFILE_DIR` для живых проверок.
[Подготовка разработки](docs/DEVELOPMENT.md), [платформы](docs/PLATFORMS.md),
[проверки и выпуск](docs/VERIFICATION.md).
