# Enki

Иконка приложения — робот в тёмном капюшоне с голубыми глазами. [Исходник и упаковка](docs/ENKI-ICON.md).

У неочевидных настроек есть кнопка «?»: по нажатию открывается объяснение опции, её значений и последствий. В браузере описаны режимы, профили, приватность и совместимость. Escape закрывает только справку; значения настроек не меняются. Тексты загружаются при открытии подсказки.

Рабочее пространство для ваших AI-агентов. [Переименование и совместимость](docs/BRANDING.md).


Общий интерфейс для OpenCode и Pi с отдельным выбором агента и модели в каждом чате. OpenCode остаётся агентом по умолчанию; история и настройки каждого движка сохраняются отдельно. [Возможности агентов и переключение моделей](docs/MODEL-SERVICES.md).

Локальный Flash Next на RTX 5090 обслуживается Strata с контекстом 262144 и GPU Vision. Выбор модели и ожидание готовности координирует Hub. [Профиль, службы и проверенные показатели](services/strata/README.md).

### Изображения и материалы

Настройки → **Изображения** подключают CPU Inference или другой совместимый API. Общие инструменты OpenCode/Pi рисуют изображения и наборы иконок, создают текстуры с согласованными normal/height/roughness/metallic-картами, сохраняют PNG/ZIP и показывают превью в чате. По умолчанию используется проверенный SDXL Lightning; LCM оставлен только явным черновым режимом. Бесшовность создаётся периодическими свёртками при генерации и декодировании, без рисования полос на краях. Для материалов есть OpenGL/DirectX и два варианта бокового освещения; для процедурных кирпича/гранита высота задана рецептом, для изображений она приближается по яркости. Vision-модель может проверить возвращённые изображения; проверка без Vision не имитируется. [Настройка и возможности](docs/IMAGE-GENERATION.md), [CPU-сервис и проверки](services/images/README.md).

Можно прикрепить PNG/JPEG/WebP и попросить перерисовать его; следующая просьба «поменяй…» редактирует последний результат этой сессии. Оригинал также сохраняется для повторной перерисовки. На одну просьбу допускаются максимум две генерации, включая исправление; ограничение хранится между перезапусками. Новые изображения рисует SDXL, правки по инструкции выполняет FLUX.2 Klein 4B; обе модели прогреты и остаются в памяти. Точная локальная ретушь и полное сохранение каждого пикселя не гарантируются.

### Общие навыки и инструменты

Веб-поиск общий для OpenCode и Pi: `mesh_web_search_search` переключается между Parallel, Exa и обычной выдачей Bing RSS при отказе провайдера. Нерелевантная RSS-выдача отклоняется; для запросов о GitHub доступен резерв через официальный API репозиториев с явной пометкой ограниченного охвата. `scope: github` запускает его напрямую. Запрос ограничен 40 секундами; 403/401 дают паузу 10 минут, 429 учитывает Retry-After. `mesh_web_search_status` показывает доступность без сетевого запроса. Общий навык `reliable-web-search` объясняет восстановление и проверку оригинальных источников. Сервисы могут быть недоступны; результат ошибки отличается от пустой выдачи. Подключение можно отключить в общем каталоге, разрешения агентов сохраняются.

Настройки → **Навыки и инструменты** объединяют SKILL.md-источники и MCP для OpenCode и Pi. Один исходный навык, одна спецификация сервиса, одинаковые имена общих инструментов; область всего компьютера и отдельного проекта. Каталог показывает обнаружение каждым агентом, действительные подключения и необходимость переоткрытия Pi. Браузер остаётся общим, нативные плагины/расширения и разрешения агентов сохраняются. [Подключение и ограничения](docs/CAPABILITIES.md).

### Цельный ход работы

Один запрос пользователя отображается как один ответ. В «Ходе работы» собраны пояснения, свёрнутые размышления и раскрываемые вызовы инструментов — без повторяющихся подписей и кнопок копирования после каждого шага. Итог отделён от действий и копируется целиком в Markdown. Модель, усилие и суммарные выходные токены доступны в «Сведениях» под ответом.

При открытии завершённой истории промежуточные действия свёрнуты. Во время выполнения они видны и не сворачиваются автоматически при появлении итога. Состояние раскрытия сохраняется при переключении чатов в пределах запуска приложения. Ошибки инструментов отмечены в заголовке; прерванный ответ и исчерпание лимита остаются видимыми и не выдаются за успешный итог. История OpenCode не изменяется.

### Чтение истории и работа с ответами

Автопрокрутка следует за ответом, пока вы внизу. Прокрутите вверх — положение сохранится при новых токенах, изменении размеров и загрузке истории. Кнопка «Вниз» возвращает к последнему сообщению и включает слежение. Последние 60 сообщений показаны сразу; более ранние раскрываются порциями без удаления истории. Положение сохраняется при переключении чатов в пределах запуска приложения.

У сообщений есть дата, время и копирование; полный ответ копируется в Markdown, код — отдельно без ограждений. Блоки кода поддерживают подсветку распространённых языков и редактируемую локальную копию. Собственное сообщение можно исправить и продолжить в новой ветке: история до него, модель и разрешения сохраняются, исправленный текст появляется в черновике для отправки. Исходная сессия и сделанные изменения файлов сохраняются. Для сообщений с вложениями используйте новое уточнение.

Индикатор проекта отражает непрочитанные обычные сессии. Внутренние подзадачи, удалённые и архивные записи не оставляют ложные метки; раскрытие проекта само по себе ничего не помечает прочитанным.

Нативная оболочка на **Tauri 2 + React + TypeScript** с двумя отдельно установленными движками: OpenCode и Pi. Каждый движок хранит собственную историю, инструменты, модели и разрешения и обновляется независимо от приложения.

На macOS приложение устанавливается в `/Applications/Enki.app` (плюс ярлыки в `~/Applications` и на рабочем столе); на Linux `.deb` ставит `/usr/bin/enki` и пункт меню «Enki»; на Windows NSIS устанавливает приложение для текущего пользователя в `%LOCALAPPDATA%\Enki`. Идентификатор WebView-профиля сохраняется, собственные данные мигрируют в `enki`. Основной исполняемый файл — `enki`, совместимый `opencode-desktop` сохраняет старые MCP-регистрации. Для чатов OpenCode нужен его сервер (по умолчанию `http://127.0.0.1:4096`). Если установленный отдельно OpenCode ещё не запущен, Desktop запускает локальный `opencode serve` и подключается после проверки `/global/health`. Уже работающий сервер не перезапускается; при закрытии приложения он продолжает работать. Удалённые SSH-серверы Desktop не запускает. Локальные чаты Pi работают без OpenCode. Переименование сохраняет идентификатор и хранилище; обновление установленной версии на Windows/Linux требует отдельной проверки.

## Таймеры и наблюдение

Попросите агента следить за задачей или выполнить действие позже: он сохраняет
разовый либо повторный таймер через общий инструмент `desktop_schedule`.
В списке чатов во время работы показывается лоадер, между проверками — часы.
Название сокращается, сохраняя место для значков. Все расписания устройства
доступны в боковом меню **Таймеры и наблюдение**: пауза, возобновление, удаление.
Работает в трее; при полном выходе пробуждения останавливаются до открытия Enki.
[Подробности и ограничения](docs/SCHEDULES.md).

Очередь и жизненный цикл отправки выделены в отдельные модули; проверка архитектурных зависимостей и строгий Rust Clippy добавлены в CI. [Изменения, проверки и границы аудита](docs/REFACTORING-20261014.md).

[Roadmap](ROADMAP.md) ведёт от явной оценки результата к воспроизводимым испытаниям, проверенной памяти проекта и общему поиску контекста для OpenCode и Pi. Первый этап — «Результат задачи» в панели контекста чата: цель, критерии, указанные проверки и ваша оценка, с необязательной передачей в Hub. [Как пользоваться и ограничения](docs/TASK-RESULTS.md).

Второй этап — [автоматические испытания](docs/EVALUATIONS.md): 12 синтетических задач на код, восстановление и браузер, независимые проверки, парные прогоны OpenCode/Pi, время и токены. `npm run eval:check` проверяет задания без модели; `npm run eval:live -- ...` явно запускает ограниченные облачные испытания в отдельных временных проектах. История пользователя и локальные GPU не используются.

### Память проекта

В контексте задачи можно связать папку с общей памятью по явному коду проекта, предложить факт или порядок действий из принятого результата и отдельно одобрить запись. Источник, ревизия и срок сохраняются в Hub; изменение источника после синхронизации снимает актуальность. OpenCode и Pi используют один раздел и опциональный MCP-поиск одобренных сведений с бюджетом и ссылками на источники. Подключение/отзыв — отдельно для локальной папки. Автоматической вставки в промпты и обучения пока нет. [Как пользоваться и ограничения](docs/PROJECT-MEMORY.md).

## Работа

- **Новый чат / ⌘N (Ctrl+N на Linux и Windows)** — новая задача: выберите проект или работайте **без проекта**. Вопросы, поиск и настройка компьютеров не требуют папки проекта.
- В меню под сообщением выберите **Этот компьютер** или **Работать удалённо…**. SSH-режим подключает отдельный сервер OpenCode и выполняет инструменты на нём.
- **Движок** выбирается в поле ввода: **OpenCode** (по умолчанию) или **Pi**. Папка проекта помнит предпочтение, новый чат его наследует, готовый чат сохраняет свой движок навсегда. Pi работает только на этом компьютере и не зависит от состояния сервера OpenCode. [Подробнее](docs/PI-ENGINE.md).
- **«В Pi»** в заголовке чата — создать чат Pi и перенести в него расшифровку текущего разговора с явной пометкой происхождения. Исходный чат не меняется, отправка — по вашей кнопке.
- **Проекты** раскрываются независимо: нажмите на название, чтобы увидеть его сессии. Можно держать открытыми несколько проектов; их состояние сохраняется. Кнопка **+** у проекта начинает в нём новый чат.
- **Меню «…» у проекта** — убрать его из списка с сохранением файлов и истории; вернуть через «Убранные проекты».
- **Передать** в заголовке чата — выбрать сессию, собрать важный контекст задачи и передать поручение или сохранить черновик. [Передача задач](docs/HANDOFF.md).
- **Недавние** под проектами — последние сессии обоих движков со всех проектов и чаты без проекта. Кнопка архива рядом открывает общий архив.
- **Управление компьютером** в настройках (**только macOS**) — Cua Driver, отдельный курсор агента и фоновые действия в окне. [Подключение и ограничения](docs/COMPUTER-USE.md).
- **API для агентов** в настройках — локальный MCP для выбора проекта/чата/модели, отправки, ожидания и чтения результата без физической мышки. Длительные задачи локальной модели поддерживают сохраняемый checkpoint-контракт, точный маркер приёмки и ограниченные продолжения после преждевременного ответа. [Инструменты](docs/AGENT-CONTROL.md) · [Agent Factory](docs/AGENT-FACTORY.md).
- **⌘K / Ctrl+K** — поиск проектов/задач и команды.
- Модель и усилие берутся из настроек выбранного агента. Для `qwen-build` на этой машине это **Qwen3.8 Flash Next / Medium**; выбор можно изменить в поле ввода.
- **Enter** отправляет, **Shift+Enter** добавляет строку. Во время работы доступна остановка; новые сообщения с вложениями можно добавлять в очередь. Каждое сообщение сохраняет свои файлы и модель.
- **Ctrl+`** — терминал, **⌘⇧R / Ctrl+Shift+R** — изменения и файлы.
- **Вложения** — перетащите или вставьте скриншот, фото, PDF, аудио, видео, текстовый файл либо нажмите значок файла рядом с «+». Большой текст из буфера прикрепляется как `.txt`; неподдерживаемые моделью PDF/аудио/видео подготавливает CPU-помощник. [Форматы, лимиты и сервис](docs/ATTACHMENTS.md).
- Меню задачи позволяет переименовать, архивировать или удалить её. Архив можно восстановить.
- Панель изменений разделяет изменения задачи и рабочую копию Git. Если сервер не сохранил исходный текст, приложение не выдумывает diff.

Светлая/тёмная тема и адрес сервера — в настройках слева внизу (⌘/Ctrl + «,»). Черновики и служебные ID разделены по серверу и проекту. У чатов без проекта — отдельные автоматически создаваемые рабочие каталоги и своя история. Автозапуск работает только для HTTP-адреса обратной петли; если порт занят другим процессом, приложение покажет причину. Если локальный OpenCode CLI не найден, экран подключения и настройки предложат открыть [официальную инструкцию установки](https://opencode.ai/docs/). Раздел Pi аналогично предлагает [официальную инструкцию Pi](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/README.md#getting-started), если Pi не найден. Приложение не устанавливает движки без выбора пользователя; они обновляются отдельно от Desktop. Журнал автозапуска находится в `~/.local/share/enki/opencode-autostart.log` на macOS, в соответствующем каталоге данных XDG на Linux и в `%LOCALAPPDATA%\enki\opencode-autostart.log` на Windows.

## Проверки и разработка

```sh
npm ci
npm test
npm run build
cargo check --manifest-path src-tauri/Cargo.toml
cargo test --manifest-path src-tauri/Cargo.toml
npm run dev                            # localhost:1425, не занимает TinyCAD на 1420
npm run tauri dev
```

Три отдельных варианта сборки. Общий `tauri.conf.json` платформенно-нейтрален;
`tauri.macos.conf.json`, `tauri.linux.conf.json` и `tauri.windows.conf.json` добавляют только своё.

Linux — `.deb` (проверено на Ubuntu 24.04, x86_64):

```sh
npm run check:linux-prereqs            # сообщает недостающие системные пакеты
npm run build:linux                    # target/release/bundle/deb/*.deb
```

macOS — `.app` + `.dmg` (Apple Silicon), ad-hoc подпись и Hardened Runtime:

```sh
npm run build:macos
python3 scripts/verify-macos.py "src-tauri/target/release/bundle/macos/Enki.app"
```

Windows — NSIS `.exe` для текущего пользователя (0.2.16 собран и установлен на Windows 11 x64 по переданным отчёту и логам):

```powershell
npm run build:windows
# src-tauri\target\release\bundle\nsis\Enki_<version>_x64-setup.exe
```

Локальный Windows-установщик не подписан сертификатом издателя. Agent Control
и зависящая от него Agent Factory на Windows пока показываются как недоступные;
остальные ограничения перечислены в [docs/PLATFORMS.md](docs/PLATFORMS.md).

На Mac владельца при конфликте глобальных пакетов используйте `env -u NODE_PATH npm …`.
Локальная сборка не имеет Developer ID/notarization.

Кружок под полем ввода показывает занятый контекст, полное окно и запас до автоматического сжатия. Рядом — режим доступа для текущего диалога. Во время работы Enter добавляет запрос в очередь; «Скорректировать сейчас» передаёт уточнение на следующий шаг агента, сохраняя выполняющиеся инструменты.

Микрофон добавляет распознанную речь в черновик. Во время записи отдельная полоса с осциллограммой, таймером, отменой и остановкой остаётся доступной даже при нескольких вложениях; отмена не отправляет аудио. В настройках укажите ASR URL `/v1/audio/transcriptions`, модель и, при необходимости, ключ. API должен поддерживать OpenAI-совместимый multipart-запрос. Ключ хранится до закрытия приложения. ## Браузер агента (0.2.18 Windows)

Windows 0.2.18 исправляет разрыв MCP при разных представлениях AppData у Desktop
и сервера, запущенного из MSIX-приложения. Браузер использует общий приватный
каталог `%USERPROFILE%/.enki/browser-runtime` и версионный MCP-мост.
Старый браузерный профиль копируется, оригинал сохраняется; каталоги чатов,
модели, разрешения и сервер OpenCode не переносятся и не перезапускаются.
Windows-установщик и его SHA256 опубликованы отдельно от macOS-пакета.
[Проверка импорта на Mac и происхождение сборки](docs/WINDOWS-MCP-INTEGRATION-20261006.md).

Кнопка «Браузер» открывает живую панель внутри Desktop. Кнопка выноса в её заголовке показывает отдельное компактное окно наблюдения: страницу нельзя случайно прокрутить, нажать или изменить её размер. Окно можно передвигать, вернуть в интерактивную панель или скрыть, пока агент продолжает работу. Доступны быстрый режим со структурой страницы и эмуляция с кликами только мышью; реальный размер страницы подстраивается под панель, а старый клик после изменения размеров возвращает свежий снимок вместо неверного действия. Панель включает: вкладки, адрес, клики, ввод, прокрутка и курсор агента. Отдельное окно Chrome не открывается: app-owned Chromium работает в фоне, а панель показывает его реальные кадры. Агент получает DOM, accessibility-layout и содержимое этой же страницы через официальный Playwright MCP. Desktop устанавливает закреплённые инструменты и подключает их к локальным OpenCode и Pi, сохраняя модели, плагины, разрешения и профиль браузера. [Архитектура, ограничения и настройка](docs/BROWSER.md).

В 0.2.42 браузерные вызовы разных чатов выполняются в независимых очередях. Ошибки параметров объясняют, что исправить, короткие наблюдения поддерживают 256–20000 символов; таймаут сообщает неопределённую доставку и не повторяет действие. Подготовка контекста ограничена по времени, а уже отправленные действия сохраняют порядок до завершения.

В 0.2.16 установка и запуск отменяются кнопкой остановки, браузер завершает работу при потере процесса Desktop, а обновление его скриптов не скачивает Chromium повторно. Проверки Pi и SSH ограничены по времени; большие диагностические потоки не блокируют дочерние процессы. Повторное подключение после смены проекта показывает подтверждённый статус, а потеря ответа браузера не повторяет уже отправленное действие. Windows-исправление от 2026-10-05 разрешает настоящий путь Chromium при перенаправлении AppData из MSIX и перепроверяет живое подключение MCP вместо устаревшего кэша. [Проверка Windows-браузера](docs/WINDOWS-BROWSER-FIX-20261005.md).


В 0.2.17 импортирована внутренняя браузерная панель из Windows-ветки: живые
кадры, вкладки/история/ручной ввод и действительные координаты курсора, общие
DOM-инструменты OpenCode/Pi. Также восстанавливается подтверждённо оборванное MCP
и первый локальный запрос ждёт его подключения. Детали и проверка Mac:
[docs/EMBEDDED-BROWSER-IMPORT-20261005.md](docs/EMBEDDED-BROWSER-IMPORT-20261005.md).

## Контекст чата

Кнопка списка в заголовке открывает расписание, файлы результатов, дочерние
сессии и источники. Повторяющиеся задания сохраняют выбранную модель/агента и
выполняются, пока Desktop открыт; занятый чат ждёт, пропущенные запуски не
накапливаются. Неподтверждённая отправка приостанавливает задание и никогда не
повторяется автоматически; причины, по которым ничего не отправлено, показываются
отдельно. [Описание и границы](docs/CHAT-CONTEXT.md).

В «Контексте задачи» также доступны тихая [диагностика времени](docs/TASK-DIAGNOSTICS.md) и [карта проекта](docs/PROJECT-NAVIGATION.md): файлы, символы и имена проверок. Карту можно явно подключить как общий инструмент OpenCode/Pi для локальной папки; она выключена по умолчанию, не выполняет команды и не добавляется в промпт автоматически.

Браузерные задачи: «Настройки → Браузер → Скорость и диагностика» создаёт отдельный чат с поддерживаемым Low/Medium, показывает доступные временные отметки и токены текущего ответа. Объединённые действия с ожиданием и компактным наблюдением сокращают обращения к модели; цепочки до шести шагов останавливаются при вмешательстве и не повторяют ввод. Навыки, история чужих сессий и настройки inference для этого не нужны. См. [системные профили](docs/BROWSER.md#system-performance-profiles-022).

Настройки разделены на приложение, общие возможности и агентов. OpenCode и Pi имеют равноправные пункты с собственными вкладками; общий каталог навыков/MCP доступен обоим. Черновики настроек Pi сохраняются при переходах и защищены подтверждением выхода. Иконка Enki — объёмная переплетённая A.

## Личная облачная библиотека

В настройках «Облачная библиотека» подключается Enki Hub: версии общих навыков/промптов/шаблонов/MCP, история и метрики моделей по устройствам. Тексты передаются опционально с фильтрацией секретов; файлы и полные выводы не собираются. История помогает разбирать ошибки и готовить проверенные кандидаты для обучения. [Установка, границы и восстановление](services/hub/README.md).

Сборки трёх платформ и проверки пакетов выполняются в [CI](.github/workflows/desktop.yml). Это не заменяет [живую проверку](docs/PLATFORM-ACCEPTANCE.md); текущие результаты и ограничения — в [VERIFICATION](docs/VERIFICATION.md).

При ошибке чтения проекта используйте «Проверить доступ к проекту»: история и черновик сохраняются, очередь не возобновляется автоматически. Подробности macOS-разрешений и подписи: [восстановление доступа](docs/PROJECT-ACCESS-RECOVERY.md).

Shared skill authoring and the reviewed document-download workflow: [SHARED-SKILL-AUTHORING.md](docs/SHARED-SKILL-AUTHORING.md).

В исходниках окно наблюдения группирует страницы выбранного чата: карточки стопкой, перестановка мышкой или Alt+←/→, независимый выбор предпросмотра. Заголовок перемещает всю группу; «Вернуть» возвращает браузер в панель. Просмотр карточки не меняет активную вкладку агента, не отправляет ввод и не меняет viewport. Проверка пассивного захвата: `node scripts/test-browser-monitor.mjs`. Изменение входит в установленную версию.


Вложения открываются из сообщения или раздела «Источники»: миниатюры, поиск по файлам сессии, просмотр изображений, текста и PDF по страницам. «Показать все» подгружает более ранние вложения. Недоступные исходники и неподдерживаемые форматы показывают статус вместо пустого просмотра.


Project and chat **Сведения** are available in their dots menus. Project properties include the paged OpenCode/Pi chat index (archived and child chats included), search, dates, IDs and copyable storage paths. Local OpenCode sizes count message/part UTF-8 payloads in its shared SQLite database; Pi sizes count the JSONL file. These are chat-data accounting figures, excluding project files, external attachments and SQLite index/free-page overhead. Remote or unsupported storage sizes remain unavailable; properties never replay tasks or change the engine database.

Ручной ввод во встроенном браузере обрабатывается отдельно от инструментов агента: клики, прокрутка и клавиши не требуют снимка структуры страницы. Текст выделяется перетягиванием и копируется Cmd/Ctrl+C. Для сайтов, запрещающих автоматизированный вход, есть кнопка открытия в системном браузере; его cookies и авторизация отдельные. Вход Google из автоматизированного Chromium не гарантируется.

### Обновления и работа в фоне

С 0.2.56 обновления распространяются через настроенный Enki Hub. Зелёный индикатор означает горячее обновление интерфейса; жёлтый — сборку из подписанных исходников на клиенте. Сборка идёт в фоне, нативная установка ждёт завершения агентов. Закрытие окна скрывает Enki в трей; полный выход — из меню трея. [Подготовка клиента, выпуск и восстановление](docs/HUB-UPDATES.md).

Мастерская — защищённый чат над проектами для доработки приложения с
контекстом исходников и проверенным выпуском в Hub. [Инструкция](docs/SELF-DEVELOPMENT.md).

Мастерская и обычные чаты передают обоим движкам русскоязычную политику ответов при каждом запросе, включая очередь и расписание. Размышления допускаются на английском. Каталог Hub проверяет версию редактирования; конфликт требует обновить черновик. Перезапуск OpenCode доступен только для процесса, запущенного текущей Enki; внешние серверы не завершаются.

Shared local model loading and multi-client GPU coordination are handled by the authenticated Hub; see [model services and reservations](docs/MODEL-SERVICES.md). Inference streams remain direct.
