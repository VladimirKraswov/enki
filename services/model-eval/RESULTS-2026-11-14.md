# Model evaluation — 2026-11-14

Same synthetic prompts and offline checks for `qwen38-flash-next` (Strata 0.1.59)
and `ornith15-122b` (PolyStrata UD-Q4_K_XL). Temperature 0, one request at a
time, no owner chats or repositories used as test input.

| Task | Qwen3.8 | Ornith 122B | What is checked |
| --- | --- | --- | --- |
| Python token bucket | PASS | PASS | capacity, refill, invalid values, clock rollback, thread lock |
| JS telemetry validation | PASS | PASS | types, NaN/Infinity, bounds, CSV escaping |
| 3D module | FAIL | FAIL | cuboid geometry, perspective defaults, 6 painter-sorted faces |
| ESP32 controller | PASS | PASS | C++17 build against Arduino/OneWire/Dallas stubs; LED, sensor, no delay |
| **Automated score** | **3/4** | **3/4** | narrow contract checks |

## Generation speed in this suite

| Task | Qwen decode | Ornith decode | Qwen output | Ornith output |
| --- | ---: | ---: | ---: | ---: |
| Backend | 106.9 tok/s | 49.2 tok/s | 3,523 tok | 2,952 tok |
| Telemetry | 102.5 tok/s | 47.1 tok/s | 2,872 tok | 964 tok |
| 3D module | 115.7 tok/s | 47.2 tok/s | 3,935 tok | 7,184 tok |

Qwen is about 2.2× faster in these direct generations. This agrees with the
earlier 110–120 vs ~45–50 tok/s observation. It is not a universal throughput
guarantee: prompt, shared expert routing and draft acceptance vary.

## Why the 3D task failed

- **Qwen:** completed the contract but used `width = 1` instead of the specified
  default `800` when the camera omitted it, so the origin was not at canvas
  centre.
- **Ornith:** at a 4K budget it was still incomplete; at 8K it completed but
  built faces with invalid vertex index 8 and sorted face objects as if they
  were indices. The test failed with an undefined `depth`, not a style opinion.

Both were allowed a generous 8K budget. No generated code was patched to pass.

## ESP32 correction

An initial verifier rejected legitimate Arduino/Dallas APIs
(`setWaitForConversion`, `DEVICE_DISCONNECTED_C`, `Serial.print(float, digits)`,
`Serial.println()`). The test stubs were corrected to the real API and both
models then passed. These false negatives are not counted against the models.

## Interpretation

On these four small engineering tasks Qwen matched Ornith's automated quality
while being much faster. This is evidence that Qwen is often sufficient; it is
not evidence that Ornith is unnecessary for harder reasoning, long-context
debugging or tasks outside this sample. The Infernix version of Ornith is tested
separately with the same suite after its 262K acceptance.
